# Agent wave — Rule 30 successor curation (2026-08-24)

## Findings

Scope was limited to this repository. The pre-existing working-tree diff was:

- `ROADMAP.md`: records the new finite-width checker.
- `docs/README.md`: documents how to run it and labels it as an implementation check.
- `experiments/bitwise_successor_check.py`: new checker, initially untracked.

The checker’s integer formula agrees with the existing tuple reference and with the
repository’s stated encoding: bit 0 is the leftmost, boundary-adjacent cell. One
reproducibility gap was found and fixed in `experiments/bitwise_successor_check.py`:
the validation conditions used Python `assert`, which are disabled by `python3 -O`.
They now raise explicit `AssertionError`s, so optimized execution cannot report a
false pass by skipping the checks. No theorem claim was changed.

## Evidence

### FORMAL

Under the documented encoding `state = Σ s[i] 2^i`, the tuple update
`next[i] = left[i] XOR (state[i] OR right[i])` becomes
`(((state << 1) & mask) | boundary) XOR (state | (state >> 1))`, followed by a
width mask. This is a finite-width implementation identity; it is not a proof about
an infinite Rule 30 trajectory.

### EMPIRICAL

The checker was run in both modes:

```text
$ PYTHONDONTWRITEBYTECODE=1 python3 experiments/bitwise_successor_check.py
PASS: h=0..12, 8191 state encodings and 16382 boundary transitions checked

$ PYTHONDONTWRITEBYTECODE=1 python3 -O experiments/bitwise_successor_check.py
PASS: h=0..12, 8191 state encodings and 16382 boundary transitions checked
```

The same bounded probe reports single-step maps as non-bijective from `h=2` onward,
which is consistent with the project’s distinction between single-step and h-step
results. A full entry-point run was stopped during its much larger `h=12` quadratic
sweep; it is not used as evidence here.

`git diff --check` passed, and the target repository has no generated bytecode or
bulk output from these checks.

## What this does not prove

This check does not prove center-column non-periodicity, eventual behavior at infinite
width, predictive-state-class coverage at any horizon, or any theorem about the
Rule 30 center column. Exhaustive agreement through `h=12` only validates this
integer implementation against the tuple reference over those finite cases.
