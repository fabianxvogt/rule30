# Research Notes

This directory is for claims we can defend, failed ideas we should not retry blindly, and the exact boundary between experiment and proof.

Suggested workflow:

1. Record a precise statement before trying to prove it.
2. Separate observed evidence from proved lemmas.
3. Log every failed proof strategy with the obstruction that killed it.
4. Save experiment parameters alongside outputs so results stay reproducible.
